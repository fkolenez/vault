
### Hidrocarbonetos
Carbono com hidrogênio
 - Alcanos  C - C 
 - Alcenos  C = C
 - Alcinos   C ≡ C

---
### Ester
C dupla O O R

- R−C=O−O−R′

---
### Haletos
Tem uma ligação com halogênio x = (F CL, BR, I)

- Aquila C = (F CL, BR, I)
- Arila  C - (Ciclo) 

---
### Álcoois
Carbono ligado a uma hidroxila (-OH)

- C - OH

---
### Fenóis
Uma ou mais hidroxilas (-OH) ligadas a um anel benzenico

- ⏣ - OH

---
### Éteres 
(não confundir com esters)
Oxigênio no meio de dois grupos

- R- O - R'

---
### Carbonila, Aldeído e Cetonas

- Carbolina é um C com uma dupla ligação com um O
	(C = O)
###### Aldeído X Cetonas

- Cetonas a carbonila (C = O), vai estar no meio da cadeia
- Aldeído a carbonila (C = O), vai estar ao final da cadeia

###### Acido carboxilico 
  - O = C - OH
