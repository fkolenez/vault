**Usuários** -> Requisitos funcionais, (RF) oque o sistema deve fazer, são as funções do sistema
Exemplos: Login de usuário processamento de pagamentos, geração de relatórios.

**Sistema** -> Requisitos não funcionais, (RNF), COMO o sistema deve fazer

**Essenciais**: imprescindíveis para o sistema, sem eles o sistema não acontece
**Importantes**: Vai ajudar no comprimento do objetivo, mas sem ele o sistema ainda ocorre
**Desejáveis**: Torna o UX mais agradável, mas não chegam a ser importante, o objetivo vai ser concluido sem eles

**Stakeholder**, todos que são interessados no sistema


RF = Função
RNF = Qualidade da função
Elas coexistem mas atuam em **dimensões diferentes**.

RF: "O sistema deve permitir que o cliente realize pagamento online".
RNF: "A transação deve ser processada em até 5 segundos com criptografia."

Numa pizza o RF é a massa, o molho e a cobertura, o RNF é o tempo de entrega, o sabor, a temperatura.
